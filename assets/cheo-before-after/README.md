# Cheo — Remodel Photos (Before / After), Classified

Client photos of real renovation jobs, sorted into job folders. Files are named
`before-N.jpg`, `during-N.jpg`, `after-N.jpg` (plus room labels in the big condo job).
All shots are iPhone-quality portrait/landscape mixes. Coastal South Florida homes
(visible in the pool/exterior shots).

**Best true before→after pairs for side-by-side sliders are marked ⭐.**

## 2026-09-11 correction pass, part 2 (independent re-verification)

Every before/after pair live on the site was individually re-checked against its
source photos (not just against this file's prose). Two more real problems turned up:

- **14-garage-to-studio's `after-1.jpg` was still wrong after the first correction
  pass** — checksum-identical to the old 09 bathroom mixup, just a different angle of
  the same wrong photo. The real after-photo (hex LED ceiling, barber chair, epoxy
  floor) was recovered from the client's own public Instagram post, cropped to remove
  the app UI and drop the only frame with an identifiable face, and is now the actual
  `after-1.jpg`.
- **`19-bath-cherry-to-bamboo` is not a separate job — it's the same bathroom as
  `07-bath-blue-to-botanical`.** Side-by-side comparison of the before-2/after-2 angles
  from both folders shows the identical room: same deer picture frame, same step stool,
  same door trim, same bamboo-pattern tile, same vanity and round mirror. The fresh
  WhatsApp export simply re-sent the same job under a new name. Removed the `19` entry
  from the site gallery so this real project isn't shown twice as if it were two
  different clients' work. The `19-bath-cherry-to-bamboo` folder is left on disk
  (extra angles of job 07) but is no longer referenced from `index.html`.
- **16-pool-spa-builds' during→after slider used mismatched camera angles** (during
  faced the tiki statue, after faced the house). Swapped the after image to `after-2.jpg`,
  which shares the tiki-statue framing with `during-1.jpg`, so the pair now reads as one
  continuous shot instead of two different views of the yard.
- All other live pairs (01, 02, 03, 06, 08, 13, 20) were individually confirmed
  same-room by direct visual comparison, including tracing 06's before→after through
  its intermediate waterproofing and tile-niche photos (same corner, same bench, same
  niche — the black ceiling is a paint finish applied late in that same job, not a
  different room).
